# WonderTime v2.0 — 4D Timeportals

**Release: 15 November 2026**

## Added
- 22 unique procedural, orbitable 3D-style dioramas for previously preview-only global destinations.
- 3 named historical phases per destination (66 total world-site phase records).
- Play-through-history, manual time scrubber, jump-to-phase cards, orbit/pinch/wheel zoom, reset and PNG export.
- Responsive full-screen historical studio with inline source URLs and site-specific evidence caveats.
- A new catalogue/guide route opening directly into Timeportals; Giza/Hawara still open their embedded deep atlas.
- Source-based rebuild contract and validation for all 22 portal records.

## Preserved
- Planet Earth globe, georeferenced markers, on-device search guide, shared 82-event Giza/Hawara history, site comparisons, local saved trail, two original deep site experiences.

## Explicit limitations
- Stylized unscaled scenes rather than survey-accurate photogrammetry or metric reconstructions.
- The rule-based guide remains offline, with no hosted language model or API requests.
- The original deep Giza WebGL/Three.js engine still needs separate online verification.
