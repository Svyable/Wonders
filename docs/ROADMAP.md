# WonderTime — execution roadmap

## The current zero-to-two release

- [x] Orbitable Earth and responsive global UI.
- [x] Natural-language local discovery, regional/topic matching and coordinates.
- [x] 24 curated georeferenced destinations, status separated by completeness.
- [x] Giza and Hawara deep atlas integration, with 82 source-informed historical chapters.
- [x] Time controls, source links, saved trail and world chronology.
- [x] Standalone single HTML distribution and source pack.

## Three next major releases

**R2 — the site engine.** Extract a shared site-view API from Giza/Hawara; add photographic/surveyed elevation mesh support, periodized visual layers and provenance badges. Integrate an internationally distributed set of first-class pilots (e.g., Göbekli Tepe, Petra, Angkor and Machu Picchu), each only after acquiring legitimate sources/assets.

**R3 — Planet Guide.** Build a secure API endpoint for retrieval-backed language queries, global place resolution and typed intents. Keep a fully functional deterministic local fallback. Include multilingual names, uncertainty-handling, accessible guided tours and click-to-cite statements.

**R4 — living knowledge network.** Add indexed world chronology, event/civilization relationships, contributor review, versioned citations, conservation status, media licenses, scholarly alternative reconstructions and personal journeys. Support offline bundles and scalable content streaming.

**Required launch gates** for every immersive site: five independently reviewed source anchors; historical and discovery dates separated; human-readable uncertainty policy; accessibility and mobile tests; rights-cleared assets; 2D fallback; versioned output with reversible changes.
